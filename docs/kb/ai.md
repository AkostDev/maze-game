# ИИ-сказки: в версии 2.0 убраны

В версии 1.1 был фоновый ИИ-помощник (сказки-уровни, названия уровней, фразы совёнка) через vibecode.moe. При переписывании на Phaser 4
игра упрощена до одной кампании, и ИИ-функции не перенесены. В коде версии 2.0 обращений к сети нет.

Если возвращать:
- Старая реализация — в истории git под меткой `v1.1` (файлы js/ai.js, js/story.js и описание в этом документе той же ревизии):
  `git show v1.1:js/ai.js`, `git show v1.1:docs/kb/ai.md`.
- Принципы, которые тогда сработали и остаются обязательными: **ИИ никогда не блокирует игру** (фоновая очередь, кэш, мгновенный локальный
  фолбэк, пауза после двух ошибок подряд); текст ИИ — только как текст (в Phaser — обычный `label()`), всё валидируется и зажимается в лимиты.
- Ключ API **не должен попадать в репозиторий**: теперь проект под git. Нужен серверный прокси; в клиенте — только адрес прокси.
  Файл js/config.js с ключом версии 1.1 лежит локально и исключён через .gitignore.
- Уровень из сказки собирался через `override` в спецификации уровня (мир, размер, количество дверей и сторожей, маска-рисунок) —
  в новой `resolveParams()` такого механизма нет, его придётся добавить.
