# Графика, камера, эффекты, звук

Источники: src/gfx/sprites.js, src/gfx/textures.js, src/gfx/mazeLayer.js, src/audio/sfx.js

## Пиксель-арт без файлов
Картинок в проекте нет: вся графика — данные в src/gfx/sprites.js, из которых `buildTextures()` при загрузке рисует текстуры.
- `PALETTE` — один символ = один цвет (основа — палитра из 16 цветов плюс коричневые, розовые, фиолетовые). `.` — прозрачный пиксель.
- `SPRITES` — карты 16×16. `m: 1` — задана левая половина (8 символов), строка зеркалится; `m: 2` — левая верхняя четверть 8×8, зеркалится по обеим
  осям (снежинка); без `m` — полные строки (яблоко, ключ). `alt` — строки второго кадра `имя_b` (шаг героя).
- Белые спрайты красятся тинтом: `key`, `yarn`, `star`, кадры дверцы и портала, все иконки.
- `GATE` — дверца 8×16 (вертикальная); горизонтальная получается транспонированием. Портал рисуется формулой (`portalRows()`, два кадра).
- `ICONS` — 12×12, `#` — белый пиксель.
- `validate()` проверяет размеры и символы; ошибка в данных останавливает загрузку с понятным сообщением и ловится test/sprites.test.js.

Текстуры (`buildTextures()`): атлас `sprites` (кадры — имена из `SPRITES`, `имя_b`, `gateV`, `gateH`, `portal_0`, `portal_1`), атлас `icons`,
атлас `ui` (`btn_цвет`, `btn_цвет_down`, `panel`, `px`, `dot`, `shadow`), `light` (дырка света), фон миров `bg_id`. Кадры лежат в сетке
с зазором 2 px (`atlas()`). Анимации (`buildAnimations()`): `имя_walk` у героев, `portal_spin`.

## Слой лабиринта — src/gfx/mazeLayer.js
Клетка — 16 px пола + стена 4 px: шаг сетки `PITCH` = 20, `CELL` = 16, `WALL` = 4. `toWorld()` переводит положение в клетках (центр клетки —
x + 0,5) в мировые пиксели. `paintMaze()` — чистая функция (работает и в Node): сначала карта «пусто / пол / стена», затем цвета —
«шахматка» пола, редкий декор, блик по верхнему краю стены, рисунок стены своего вида у каждого мира (`wallAccent()`), передняя грань
стены высотой 3 px и тень под ней, жёлтый коврик у выхода. `mazeCanvas()` кладёт результат в canvas; `buildWorld()` регистрирует его текстурой
`maze` (старая удаляется) и показывает одним Image — слой рисуется раз на уровень.

## Мир и глубина — `buildWorld()` в GameScene
Порядок слоёв (`DEPTH`): фон-плитка → лабиринт → нить → клубок у старта, порталы, тень героя → находки, ключи, домик → дверцы → сторожа → герой
→ частицы и огоньки подсказки → туман. Мировые координаты — «арт-пиксели» лабиринта; на экран их увеличивает камера.

## Камера — `fitCamera()`
- Масштаб `z` — **целое** число пикселей устройства на пиксель рисунка: только так пиксель-арт не «плывёт».
- Лабиринт показывается целиком, если клетка при этом не мельче `MIN_CELL` (34 CSS px); иначе `z` минимальный и камера следует за героем
  (`fits = false`, в HUD появляется кнопка обзора; `toggleOverview()` временно показывает всё). Крупнее `MAX_CELL` клетка не бывает.
- Ночью камера всегда близко (≈ 8 клеток по короткой стороне).
- Границы камеры = лабиринт + поля под HUD (`hudInsets()`). Если лабиринт меньше экрана, границы расширяются до размера экрана — и он
  встаёт по центру свободной области; отдельной ветки «без слежения» нет.
- Камера следит за точкой `target`, а не за спрайтом героя: спрайт подпрыгивает при ходьбе, камера — нет.

## Эффекты
- Нить клубка: `trail` (Graphics) — прямоугольник 2 px на каждый шаг, цвет `hero.thread`.
- Подбор предмета `pickUp()`, тряска `shake()`, частицы `burst()` (эмиттер на каждый всплеск, сам удаляется), огоньки подсказки `showHint()`.
- Ночь `placeFog()`: картинка `light` (непрозрачная темнота со ступенчатой прозрачной дыркой радиуса `LIGHT_HOLE` из `LIGHT_SIZE`) по центру героя
  и четыре прямоугольника вокруг. Масштаб картинки = `lightR × PITCH / LIGHT_HOLE`; `lightR` плавно догоняет `logic.lightRadius`.
- Надписи над полем рисует HUD в экранных координатах (`floatAt()` → `toScreen()` → `floatText()`): текст в мировых координатах
  увеличивался бы камерой и стал бы грубым.
- Сторожа: покачивание, зеркалирование по `dirX`, во сне — серый тинт и значок `zzz`; догоняющий подкрашен красным.

## Звук — src/audio/sfx.js
Файлов нет: эффекты `SFX` — короткие тоны и шум на WebAudio (прямоугольная волна — «8 бит»), музыка `SCALES` — генеративная мелодия
в пентатонике, своя у каждого мира и у меню. Звуковая система Phaser отключена (`audio.noAudio`).
- `sfx.play(name)`, `sfx.startMusic(id)` (до первого жеста только запоминает — заиграет после `unlock()`), `sfx.stopMusic()`, `sfx.buzz()` — вибрация.
- `sfx.configure()` применяет настройки `sound`, `music`, `vibration`. AudioContext создаётся только по жесту пользователя (требование iOS и Chrome).
