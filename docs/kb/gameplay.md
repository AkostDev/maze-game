# Игровая механика: движение, ввод, правила, враги, оценки

Источники: js/game.js, js/input.js

## Движение (game.js)
Герой всегда стоит в клетке или идёт между двумя соседними (`player.from → player.to`, прогресс `t` 0…1).
`update()`: бюджет пути за кадр = `dt * level.speed`; цикл (до 6 клеток за кадр): если не идёт — `chooseDir()` → `startMove()`;
при `t ≥ 1` — `arrive()`. Логика стоит, пока `paused | won | lost | !started`; анимации (моргание, двери, подсказка) идут всегда.
Первое действие игрока вызывает `begin()` → `started = true` → колбэк `onStart`.

`chooseDir()` — приоритеты:
1. `traceQueue` (ведение пальцем) — следующая клетка маршрута.
2. Режим `'step'` (по умолчанию) → `chooseStep()`: очередь нажатий `stepQueue` (≤ 3; непроходимый шаг очищает очередь и даёт `bump()`),
   затем повтор при удержании: `heldDir` после `holdDelay` секунд, строго по прямой, без автоповоротов.
3. Режим `'glide'`: буфер поворота `bufferDir` (живёт 1.5 с на ходу), удержание с автоповоротом в коридоре, скольжение `gliding` до развилки.

API ввода у `Game`: `push()` (нажатие/свайп/тап), `setHeld()` (удержание + задержка повтора), `release()`, `traceTo()` (путь BFS ≤ 6 клеток
до клетки под пальцем), `tapToward()`.

## Ввод (input.js)
| Жест | Действие |
|---|---|
| Палец/мышь поставлены на героя (радиус max(34 px, 0.95 клетки)) | режим trace: `traceTo()` на каждую новую клетку под пальцем |
| Свайп (порог max(12, min(26, 0.32 × масштаб)) px, «плавающий якорь») | на каждую смену направления: `push()` + `setHeld(dir, touchRepeat)` — 0.55 с, малыш 0.8 с |
| Короткий тап (< 12 px, < 400 мс) | `tapToward()` — шаг в сторону касания |
| Два пальца / колесо | зум `Renderer.zoomBy()`; пинч отменяет движение |
| Клавиши `KEYMAP`, кнопки D-pad | `push()` + `setHeld(dir, KEY_REPEAT)` — 0.28 с; `e.repeat` игнорируется |
`Input.active()` — ввод принимается только если есть уровень, нет паузы/победы/поражения и колбэк `isActive` из main.js (игра идёт, модалка закрыта).
`releaseAll()` — при паузе, остановке, потере фокуса окна.

## Проход, двери, ключи, выход
`passable(i, d)`: стена открыта И (нет двери ИЛИ дверь открыта ИЛИ есть ключ её цвета) И (сосед — не выход ИЛИ выход открыт).
Дверь открывается в `startMove()` → `openGate()`: ключ расходуется (`keysHeld.delete`), событие `gateOpen`.
`bump()` (не чаще раза в 0.45 с): стена — звук; закрытая дверь — тряска + `gateLocked`; закрытый выход — `exitLocked`.
Выход («домик») открывается, когда собраны все обязательные предметы (`remaining === 0`) → `exitOpen`. Победа — приход в клетку выхода.

`arrive()`: шаг++, след `trail`, отметка `visited`, подбор предмета `take()`, подбор ключа (`key`), победа, телепорт `teleport()`
(защита от зацикливания — `justTeleported`). `lastProgress` обновляется при новой клетке/предмете/ключе — на нём держится «застрял».

## Предметы и бонусы — `take()`
- `item` — обязательная находка: `remaining--`, событие `collect {left}`.
- `clock` (уровни с таймером): +7 с (малыш +10). `firefly` (ночь): `lightRadius` +0.45, максимум 3.2. `heart` (сторожа): +1 жизнь, максимум `maxHearts + 2`.
  Бонусы дают событие `bonus {kind}` и идут в `bonusTaken`.

## Подсказка-клубочек — `useHint()`
BFS по проходимым сейчас рёбрам; цели: несобранные находки, невзятые ключи, двери, к которым уже есть ключ, открытый выход — берётся ближайшая.
Путь обрезается: teen 14 клеток, pro 10; живёт 7 с (`hint.life`). Запас — `AGES[age].hints` (tiny 99 → в HUD «∞»). Нет запаса → `noHints`.
Каждая подсказка снижает звёзды (см. ниже) и очки (−100).

## Сторожа — `updateEnemies()`, `enemyNext()`
- `patrol` — ходит по `route` туда-обратно; `wander` — случайно, старается не разворачиваться; `chaser` — идёт по градиенту
  `chaseField` к игроку, если расстояние ≤ `level.chaseRange` и игрок не в безопасной зоне.
- Не заходят: в выход, в порталы, в безопасную зону у старта (`startDist < 3`), сквозь закрытые двери.
- Сон: цикл `AGES[age].sleep = [бодрствует от, до, спит]` секунд; спящий (`asleep`) безопасен и неподвижен. Первый сон → `enemySleep`.
  Сон обязателен: без него патруль в единственном коридоре делал уровень непроходимым.
- Столкновение: расстояние² < 0.36, нет неуязвимости, не идёт телепорт → `onHit()`: у малыша (или если жизней нет) — оглушение 0.9 с
  и неуязвимость 2.4 с без потери; иначе −1 жизнь, неуязвимость 2.2 с; 0 жизней → `lose('caught')`.

## Таймер, ночь, «застрял»
- `rules.timer`: `timeLeft` убывает, тик в последние 10 с; в ноль: малыш → `overtime` (играет дальше), остальные → `lose('time')`.
  `rules.countUp` (лабиринт дня) — секундомер в HUD по `elapsed`.
- `rules.dark`: туман; радиус света `lightRadius = level.fog` клеток; посещённые клетки чуть видны (рисует `drawFog()`).
- Нет прогресса 25 с (малыш 12 с) и нет активной подсказки → событие `stuck` (не чаще раза в 25 с).

## Итоги
`win()` → конфетти, `result(true)`, `onWin` через 0.9 с. `lose(reason)` → `onLose` через 0.8 с. Для tiny проигрыша нет вообще.

Звёзды — `computeStars()`:
- tiny: 3; 2 — если подсказок > 3, было `overtime` или столкновений > 3.
- с таймером: доля оставшегося времени ≥ 0.33 (kid 0.25) → 3; ≥ 0.1 → 2; иначе 1.
- со сторожами: 0 столкновений → 3; 1 → 2; иначе 1.
- иначе по отношению `steps / optimalSteps` к порогам `AGES[age].stars` (ночью пороги ×1.25).
- подсказки: хотя бы одна → максимум 2 звезды; больше двух → максимум 1.

Очки (только при победе): `500 + находки×100 + двери×150 + бонусы×40 + звёзды×300 + max(0, (par×1.6 − elapsed)×12) − подсказки×100 − столкновения×150`
(+ `timeLeft×15` с таймером), где `par = optimalSteps / speed`; затем × множитель возраста (tiny 1, kid 1.2, teen 1.5, pro 2), минимум 50.
