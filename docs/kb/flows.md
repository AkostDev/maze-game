# Потоки: загрузка, сцены, навигация, старт и конец уровня

Источники: src/main.js, src/config.js, src/scenes/BootScene.js, src/scenes/PauseScene.js, src/scenes/ResultScene.js, index.html

## Загрузка
index.html → src/main.js (`start()`): ждёт шрифт Tiny5 (не дольше 2,5 с) → создаёт Phaser.Game (холст в пикселях устройства, см. phaser.md) →
кладёт в реестр игры `dpr` и `safe` (вырезы экрана из отступов блока `#safe`) → применяет настройки звука → регистрирует service worker
(кроме режима `?test`). Первая сцена — `BootScene`: `buildTextures()`, `buildAnimations()`, убирает надпись `#boot`, открывает меню.
`MenuScene` при первом показе ставит `KLUBOK.ready = true` — этого ждут проверки в браузере.

Отладка в консоли: `window.KLUBOK` = { game, progress, sfx, version, ready, go(key, data) }. `KLUBOK.go('Game', { index: 12 })` открывает
любую сцену из любого состояния.

## Сцены
| Сцена | Что это | Как попасть |
|---|---|---|
| Boot | сборка текстур | старт |
| Menu | название, выбор героя, «Играть» | из Boot; кнопка «Меню» в паузе; назад из Levels и Settings |
| Levels | страницы миров по 10 уровней | из меню, паузы, итогов; `data.page` — номер мира |
| Settings | переключатели и сброс прогресса | из меню |
| Game | игровое поле; `data.index` — уровень с нуля | «Играть», кнопка уровня, «Дальше», «Заново» |
| Hud | интерфейс поверх поля | запускает `GameScene` в `create()` |
| Pause | модальное окно | `pauseGame()` |
| Result | итоги победы или поражения | `showResult()` |

Порядок в массиве сцен в src/main.js = порядок отрисовки: Hud, Pause и Result рисуются поверх Game.

Переходы — только через `goto()` (src/ui/kit.js): он останавливает Hud, Pause, Result и Game (если цель — не сама игра) и запускает нужную сцену.
Прямой вызов `scene.start` из модальной сцены оставил бы игру висеть под новым экраном.

## Старт уровня — `GameScene.create()`
1. `hasCard` — нужна ли карточка-знакомство (`introFor()` и уровень ещё не пройден); `hudInsets()` — поля под HUD.
2. Пропорции свободной области → `levelSpec()` → `buildLevel()` → `new Game(level, { onEvent })`.
3. `buildWorld()` — слой лабиринта и спрайты; `fitCamera()`; `bindInput()`; музыка мира; запуск сцены Hud.
4. Игра «не начата» (`logic.started = false`), пока игрок не сделал первое действие: сторожа стоят, время не идёт.

## Пауза
`pauseGame()` (кнопка, Esc/P, потеря фокуса окна через `autoPause()`): пауза Hud, запуск Pause, пауза Game. `PauseScene.resume()` возобновляет
обе сцены и зовёт `onResume()` — тот заново считает камеру и перестраивает HUD (в паузе могли включить экранные стрелки).

## Конец уровня
Событие `win` → `finish()`: `progress.recordWin()`, звук, частицы, через 1 с `showResult()` — Hud останавливается, запускается Result
с `{ index, result, rec }`. Событие `lose` → то же без записи, через 0,8 с. Игровая сцена под итогами продолжает жить (анимации),
но логика уже не принимает ввод (`won` / `lost`).

`ResultScene`: «Дальше» → `primary()` → Game с `index + 1`; «Заново» → `retry()`; список → `toLevels()`. `news()` — строка о новом мире
или конце кампании. После 50-го уровня «Дальше» ведёт в бесконечный режим (уровни 51, 52, …).

## Клавиши
| Где | Клавиши |
|---|---|
| Игра | стрелки / WASD — шаг (удержание — повтор); H — подсказка; R — заново; M — обзор лабиринта; Esc, P — пауза |
| Пауза | Esc, P, Enter, пробел — продолжить; R — заново |
| Итоги | Enter, пробел — главное действие; R — заново; Esc — к уровням |
| Меню | Enter, пробел — играть; ← → — сменить героя |
| Уровни | ← → — листать миры; Enter — играть текущий уровень; Esc — в меню |
| Настройки | Esc — в меню |

## Изменение размера окна и поворот
`fit` в src/main.js: новое значение `dpr` и `safe` в реестре → `game.scale.resize`. Сцены интерфейса (`UiScene`) на событие resize целиком
перестраиваются (`rebuild()`), `GameScene` пересчитывает камеру (`fitCamera()`); уровень при этом не пересоздаётся.

## Настройки и звук
`toggleSetting()` (src/scenes/SettingsScene.js) — единственное место, где настройка меняется из интерфейса: пишет в `progress`,
вызывает `sfx.configure()`. Звук включается первым жестом пользователя (`sfx.unlock()` на pointerdown / keydown) и засыпает, когда вкладка скрыта.
