# Генерация уровней

Источники: js/levels.js, js/maze.js

## Конвейер — `buildLevel()`
`spec` → `resolveParams()` (числа: размер, количества, правила) → K кандидатов через `designCandidate()` (K: tiny 8, > 500 клеток 4, иначе 6),
берётся с лучшим `score` → если ни один не решаем: до 20 попыток упрощения (минус дверь, без порталов, после 4-й — без фигуры) →
объект level (см. data.md). Всё детерминировано сидом; `Math.random` в генерации не используется (только в рантайме игры).

Сиды: кампания `v1|age|mode|index`, день `daily|дата|age`, сказка `story|id|age`. Отдельные потоки RNG (`makeRng()`):
`params|seed`, `level|seed`, `cand|seed|k|…`, `fallback|seed|n`, `deco|seed` (декор в рендере), `tale|seed` (локальная сказка).
⚠ Любая правка генерации меняет все существующие уровни кампании и «лабиринт дня» — рекорды перестают быть сравнимы.

## `resolveParams()`
- Сложность `d = difficulty(index)`: линейно 0→1 за `CAMPAIGN_LEVELS` (40), «передышка» −0.035 на первом уровне мира;
  после 40-го — бесконечный режим (`endless`, d = 0.85…1 случайно). Сказка задаёт `override.sizeT` вместо d.
- Размер: `L = lerp(age.size, d)`, площадь `L²` (ночь ×0.8, на время ×0.92, сторожа ×1.05); cols/rows из площади и `aspect`
  (зажат 0.62…1.65; `fixedAspect` → 1). Минимум 3×3, для фигур 7×7.
- Фигура: каждый 4-й уровень (`index % 4 === 3`) при `index ≥ age.shapeFrom` и `L ≥ 7` — из `SHAPE_POOL` по хэшу сида; лабиринт дня — всегда фигурный;
  `override.ascii` → `asciiMask()` (рисунок ИИ, масштаб 1–3). Маска обрезается `trimMask()`.
- Двери/порталы: включаются с уровня `gateFrom` / `portalFrom` и растут до максимума к концу кампании; tiny — максимум 1 дверь;
  дверей не больше `клеток / 18`. Предметы: `lerp(age.items, d)`.
- Правила по режиму: time → `timer`, enemies → `enemies`, dark → `dark`, daily → `countUp`. Враги ставятся только в режиме enemies или по `override.enemies`.
- Петли (`braid`): `lerp(age.braid, d)`, +0.12 со сторожами (чтобы было где разойтись); `override.loops` пересчитывает.
- Бонусы (`extras`): часы `1 + round(2d)` при таймере; светлячки `2 + round(2d)` ночью; сердце — если врагов ≥ 3 и у возраста есть жизни.
- Алгоритм — из `age.algos` по хэшу сида; `algoOpts.newest` для `growingTree()`.

## `designCandidate()` — порядок построения (решаемость по построению)
1. Идеальный лабиринт выбранным алгоритмом на маске. Старт и выход — концы «диаметра» (два BFS через `farthest()`).
2. `mainPath` — единственный путь старт→выход. Двери ставятся на рёбра этого пути (в идеальном лабиринте это мосты), равномерно, не ближе 3 клеток.
3. Регионы — области между дверями (`region[cell]`). Петли `braid()` добавляются **только внутри одного региона** и не трогают выход
   (выход остаётся тупиком) — иначе дверь можно было бы обойти.
4. Ключ k — в регионе перед дверью k (запасной проход: любой более ранний регион); предпочтение тупикам вдали от пути; малышам — рядом с путём.
5. Предметы — `placeSpread`: выборка самых дальних от уже занятых клеток + бонус за тупик + `age.offPath` × удалённость от пути.
6. Порталы — пары тупиков одного региона, далеко друг от друга (≥ max(6, 0.9·√клеток)). Затем бонусные предметы.
7. `greedyTour()` — жадный обход (ближайшая цель → … → выход) с учётом дверей и порталов: проверка решаемости и `optimalSteps`.
8. Враги: далеко от старта (`dStart ≥ safe + 1`, safe 3…6), не на выходе/порталах/предметах; тип: `chaser` с уровня `chaserFrom` (35 %),
   `wander` с `wanderFrom` (40 %), иначе `patrol` (маршрут 3–7 клеток, не через двери и предметы; короче 3 → wander).
9. `score` = покрытие маршрутом (≤ 2.6) − 2.5·|доля развилок на пути − `age.decisionTarget`| + шум.

`timeLimit = ceil(optimalSteps / age.speed × timeFactor + 6)` секунд.

Инварианты, которые проверяет tests/levels.test.js на 812 уровнях: все клетки достижимы; каждая дверь обязательна (без неё выход недостижим);
ключ достижим до своей двери; объекты не делят клетку; враги не ближе 3 клеток к старту; `required ≥ 1`; `optimalSteps > 0`.
Новая механика, влияющая на проходимость, должна учитываться в `greedyTour()` и в проверках теста.

## Миры, режимы, кампания
- Мир уровня: `worldFor(index) = floor(index / 8) % 5` (`LEVELS_PER_WORLD` = 8, 5 миров × 8 = 40). Название: `localTitle()` из `world.names`
  (ИИ может подменить — `AI.levelName()`); после 40-го — с «✦». Сказка задаёт мир через `override.world`.
- `MODES` — 6 режимов (`id, name, desc, icon, color`); `CAMPAIGN_MODES` — четыре с картой уровней и прогрессом: classic, time, enemies, dark.
- Лабиринт дня: `dailySpec()` — индекс сложности по возрасту (tiny 14, kid 22, teen 26, pro 32), размеры не зависят от экрана.

## maze.js — что есть
- Генераторы (`generators`, все работают на любой связной маске): `backtracker()` — длинные коридоры; `growingTree()` — смесь (параметр newest);
  `prim()` — много коротких тупиков; `kruskal()`; `wilson()` — равномерное дерево; `huntAndKill()`. Точка входа — `generate()`.
- `braid(g, ratio, rng, allow)` — убирает долю тупиков, `allow(i, j)` ограничивает соединения.
- `bfs(g, start, { blocked(i, d, j), links })` → `{ dist, prev }`; `links` — Map порталов (тогда `d = −1`); `pathTo()`, `farthest()`, `multiBfs()` (в levels.js).
- Фигуры: `SHAPES` — функции от нормированных X, Y ∈ [−1, 1]; `shapeMask()`, `shapeFill()`, `asciiMask()` (4…24 строк/столбцов, ≥ 12 клеток),
  `largestComponent()`, `trimMask()`. Метрики: `metrics()`, `decisionsOnPath()`.
