# Волшебный клубок — детская игра-лабиринт

Браузерная игра «пройди лабиринт» для детей от 3 лет, подростков и взрослых.
Стек: **чистый JavaScript + Canvas 2D + CSS**, без библиотек и сборки. Язык интерфейса — русский.
Двойной клик по `index.html` работает (скрипты обычные, не ES-модули — ради `file://`). PWA/офлайн: `python3 -m http.server 8080`.

## Как работать с проектом (экономно — это требование пользователя)
Пользователь начинает новый чат под каждую идею. **Не перечитывай исходники целиком** — в проекте есть база знаний `docs/kb/`.

1. **Карта кода** подгружена в конце этого файла (`docs/kb/MAP.md`): все функции с диапазонами строк, CSS-разделы и классы, реестры имён
   (иконки, звуки, события, настройки…). Генерируется автоматически хуком после каждой правки.
2. **Открой 1–2 документа по задаче** (таблица ниже), а не код «на всякий случай».
3. **Читай код точечно**: `Read` с `offset`/`limit` по диапазону из карты, `Grep` для поиска. Файлы целиком (особенно `ui.js`, `sprites.js`,
   `style.css`) — только если правка действительно затрагивает весь файл. Бинарник `tools/.snap` не читать.
4. **Проверка одной командой** (вывод в несколько строк): `tools/verify.sh` — логика; `tools/verify.sh ui` — плюс аудит вёрстки 320–768 px.
   После правок интерфейса ещё снимки: `tools/screens.sh <пресет>` (телефон 360 px и ПК 1280 px) — пользователь смотрит игру и там, и там.
5. **Обнови базу знаний** в том же ходе: поправь документы, чьё содержание изменилось (поведение, структуры данных, новые рецепты/грабли),
   затем `python3 tools/kb.py stamp`. Хук Stop напомнит, если код разошёлся с базой; SessionStart сообщит, что изменилось вне сессии.
   Писать в базу только то, чего не видно из карты: связи, инварианты, причины решений, «куда лезть». Номера строк в документы не писать.

Не заводи субагентов для чтения кода — база знаний дешевле. Агент `ui-check` (Sonnet) — только для широкой визуальной проверки многих экранов.
Скиллы: `/verify` (проверка), `/screens` (снимки экранов), `/kb-sync` (сверка базы знаний).

## Архитектура в одном абзаце
Все модули — IIFE, регистрируются в `window.MZ`; порядок подключения в `index.html` важен. `main.js` (`MZ.app`) — контроллер: связывает
`Game` (логика по клеткам), `Renderer` (canvas), `Input` (жесты/клавиши), `ui.js` (экраны DOM поверх canvas, HUD, модалки), `progress.js`
(профили, рекорды, достижения в localStorage), `ai.js` + `story.js` (фоновый ИИ и локальные сказки). `levels.js` строит уровень из
сидированного `spec` поверх `maze.js` (сетка с битмасками проходов N=1, E=2, S=4, W=8); `sprites.js` — процедурная графика, `audio.js` — синтез звука и речь.

## Ключевые решения (не ломать)
- **ИИ никогда не блокирует игру**: фоновая очередь + кэш + мгновенный локальный фолбэк; цепочка моделей `gpt-5.4-mini` → `gpt-5.5`,
  circuit breaker (2 ошибки → пауза 5 мин). Текст ИИ — только через `textContent`, всё валидируется и зажимается в возрастные лимиты.
- **Решаемость по построению**: двери — на рёбрах пути старт→выход идеального лабиринта (мосты), ключ k — в регионе до двери k,
  braid добавляет петли только внутри региона. Проверяется на 812 уровнях.
- Уровень детерминирован от сида `hash(age|mode|index)`; размеры подстраиваются под экран (кроме «Лабиринта дня» — там фиксированные,
  чтобы рекорды были сравнимы). Правка генерации меняет все существующие уровни.
- Возрасты: `tiny` 3–5, `kid` 6–8, `teen` 9–12, `pro` 13+. Для `tiny` проигрыша нет. Режимы: `classic`, `time`, `enemies`, `dark`, `story`, `daily`;
  правила уровня — в `level.rules` ({timer, enemies, dark, countUp}), а не в имени режима.
- Сторожа засыпают по циклу (`AGES[age].sleep`), спящие безопасны — иначе патруль в единственном коридоре делал уровень непроходимым.
- **Движение по умолчанию пошаговое** (`moveMode = 'step'`, требование пользователя): нажатие/свайп/тап = одна клетка, очередь ≤ 3,
  удержание повторяет шаги по прямой. «Бег до развилки» (`'glide'`) — опция в настройках.
- Озвучка: для речи — отдельный текст с числами словами и родом (`goalSpeech()`, второй аргумент `owl()`), не экранная строка с цифрами.
- Ночной режим: камера всегда близко (≈ 8 клеток по короткой стороне), туман непрозрачный.
- Прогресс кампании — по ключу `режим@возраст`. Хранилище: `klubok.v1` (прогресс), `klubok.ai.v1` (кэш ИИ); новые поля — с миграцией в `load()`.

## Дизайн (подробно — docs/kb/ui.md)
Mobile-first, токены на `:root`, тёмная тема (`prefers-color-scheme` и `[data-theme]` — два блока), малышам крупнее (`body[data-age=tiny]`).
Unbounded — только h1/h2; остальное Nunito. Акценты-«пряжа»: красный #FF5B4F, солнечный #FFBE2E, бирюзовый #13A89E, виноградный #7A5CFA (ИИ).
Фирменная деталь — «стежок» (пунктир внутри карточки `.patch`). Кнопки ≥ 46 px (малышам ≥ 56), текст обязан помещаться на 320 px.
