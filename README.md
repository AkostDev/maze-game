# Волшебный клубок

Добрая пиксельная игра-лабиринт для детей от 3 лет и взрослых. Собери находки, открой домик, обходи сторожей —
с каждым уровнем чуть сложнее. Сделана на **Phaser 4**, работает на смартфонах, планшетах и ПК, ставится как приложение (PWA) и играет офлайн.

**Играть: https://akostdev.github.io/maze-game/** — на телефоне откройте ссылку и добавьте страницу на экран «Домой».

## Как запустить у себя

Нужен любой статический сервер (игра написана ES-модулями, двойной клик по `index.html` не сработает):

```sh
npm start                 # то же, что python3 -m http.server 8080
# затем http://localhost:8080
```

На телефоне в той же Wi‑Fi сети: `python3 -m http.server 8080 --bind 0.0.0.0` и откройте `http://<IP-компьютера>:8080`.
Устанавливать ничего не обязательно: движок и шрифт лежат в репозитории. `npm install` нужен только для тестов в браузере и обновления Phaser.

## Как играть

- **Телефон и планшет:** проведи пальцем в нужную сторону — герой сделает шаг. Не отпускай палец — пойдёт дальше; веди пальцем в другую
  сторону — повернёт. Короткое касание — шаг в сторону касания. В настройках можно включить кнопки-стрелки на экране.
- **Клавиатура:** стрелки или WASD — ходить, H — подсказка, M — показать весь лабиринт, R — заново, Esc — пауза.
- Собери все находки мира (яблоки, ракушки, конфеты…) — домик откроется. Дойди до него.
- Лампочка внизу — подсказка: покажет дорогу к ближайшей цели. Три на уровень; с подсказкой звёзд будет меньше.
- Звёзды — за короткий путь: чем меньше лишних шагов, тем больше.

## Что внутри

Одна кампания из **50 уровней в пяти мирах** (лес, море, конфетная страна, снежное королевство, космос), дальше — бесконечные лабиринты.
Никаких возрастов и режимов: первый уровень — крошечный лабиринт 4×4, а новое появляется по одному и с объяснением:

| Уровень | Что появляется |
|---|---|
| 1 | находки и домик |
| 4 | цветные ключи и дверцы |
| 10 | лабиринты в форме сердца, звезды, цветка… |
| 13 | порталы |
| 21 | сторожа: три жизни; сторожа иногда засыпают, и мимо спящего можно пройти |
| 27 | бродячие сторожа |
| 31 | ночные уровни: фонарик и светлячки |
| 39 | сторож, который догоняет |

Пять героев на выбор (ёжик, котик, лягушонок, пингвин, зайка) — каждый разматывает за собой нить своего цвета.
Каждый лабиринт создаётся программой и гарантированно проходим; на разных экранах один и тот же уровень получает удобную форму.

## Технологии

- **Phaser 4.2.1**, WebGL, ES-модули, без сборки. Движок — готовым файлом в `vendor/`.
- **Пиксель-арт из кода:** спрайты — текстовые карты 16×16 с общей палитрой (`src/gfx/sprites.js`), текстуры рисуются при загрузке.
  Звук и музыка синтезируются на WebAudio. Единственные файлы-ассеты — пиксельный шрифт Tiny5 (лицензия OFL, `assets/fonts/`).
- **Сцены:** Boot → Menu ⇄ Levels / Settings → Game, поверх неё Hud, Pause, Result (`src/scenes/`).
- **Логика отдельно от движка:** генерация уровней и правила игры (`src/core/`) — чистый JavaScript, тестируется в Node.

```
src/core/     лабиринты, уровни, правила игры, прогресс — без Phaser
src/gfx/      спрайты-данные, сборка текстур, картинка лабиринта
src/audio/    синтез звука
src/ui/       кнопки, панели, текст, метрики экрана
src/scenes/   сцены Phaser
test/         тесты Node и смоук в браузере
tools/        проверка, снимки экранов, база знаний, перенос Phaser
docs/kb/      база знаний проекта (для разработки с Claude Code)
```

## Разработка

```sh
npm install              # Phaser (для обновления движка) и playwright-core (для проверок в браузере)
tools/verify.sh          # тесты логики: 210 уровней, автопилот, прогресс, данные графики — пара секунд
tools/verify.sh ui       # то же + смоук всех сцен в headless Chromium (телефон и ПК)
node tools/screens.mjs menu game    # снимки экранов; список пресетов и ключей — в начале файла
npm run vendor           # после смены версии phaser в package.json: обновить vendor/ и скиллы
npm run live             # проверить опубликованную игру на GitHub Pages
```

Публикация — обычный `git push` в ветку `main`: GitHub Pages раздаёт репозиторий как есть (сборки нет), сайт обновляется за минуту.

Для проверок в браузере нужен Chromium из кэша Playwright: `npx playwright-core install chromium`.

Проект ведётся с Claude Code: правила работы — в `CLAUDE.md`, знания о коде — в `docs/kb/`, официальные скиллы Phaser 4 — в `.claude/skills/phaser-*`.
История версий и планы — `docs/PLAN.md`. Версия 1.1 (чистый JS и Canvas, режимы, возрастные группы, ИИ-сказки) — в истории git под меткой `v1.1`.
