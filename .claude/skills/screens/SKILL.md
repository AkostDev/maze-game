# Снимки экранов

Сервер и браузер поднимаются сами, окна не открываются. Аргументы пользователя (если есть) — названия экранов: $ARGUMENTS

1. Выбери пресеты под задачу: `menu levels settings intro game hint pause result lose`.
2. Запусти: `node tools/screens.mjs <пресеты>` — по два снимка на пресет (телефон стоя и ПК).
   - только телефон `-m`, только ПК `-d`; добавочные размеры после них: `-l` — телефон лёжа 780×360, `-t` — планшет 1024×768
   - другой уровень (с нуля) и герой: `node tools/screens.mjs --level 30 --hero bunny game` (30 — ночь, 22 — сторожа, 12 — порталы, 0 с `intro` — обучение)
   - своё состояние: `node tools/screens.mjs --js "KLUBOK.progress.setSetting('dpad', true); KLUBOK.go('Game', { index: 22 })" mycase`
     (код — одной строкой, без комментариев `//`; сохранение уже содержит пройденные уровни до `--level`)
   - крупный снимок в пикселях устройства: `--hd` (по умолчанию ужат до CSS-размера — так дешевле по контексту)
3. Посмотри снимки через `Read` по напечатанным путям. Значок `⚠` рядом с путём — ошибка на странице, её надо чинить.
4. Пользователю, если он просил показать, — назови пути к файлам; чтобы открыть игру самому: `npm start` → http://localhost:8080.

Нет браузера в кэше Playwright — `npx playwright-core install chromium`. Подробности и отладка — `docs/kb/testing.md`.
