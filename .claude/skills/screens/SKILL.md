# Снимки экранов

Сервер поднимается сам, окна не открываются. Аргументы пользователя (если есть) — названия экранов: $ARGUMENTS

1. Выбери пресеты под задачу: `welcome welcome2 home levels story records achievements settings profiles intro game game-time game-enemies game-dark game-story pause result lose`.
2. Запусти: `tools/screens.sh <пресеты>` — по два снимка на пресет (телефон `-m`, ПК `-d`; можно только один размер ключом).
   - другой возраст/герой/режим/уровень: `AGE=tiny HERO=bunny MODE=dark LEVEL=12 tools/screens.sh game`
   - своё состояние: `tools/screens.sh -j "MZ.app.startCampaign('time', 7); MZ.app.pause()" mycase` (JS выполняется после создания профиля с прогрессом)
   - светлая тема (на этом Mac системная — тёмная): добавь в `-j` `MZ.progress.setSetting('theme','light'); MZ.app.applySettings();`
   - чёткий снимок 2x: `HD=1` (по умолчанию 1x — так дешевле по контексту)
3. Посмотри снимки через `Read` по напечатанным путям. Строка `⚠ PAGE ERROR` рядом с путём — исключение на странице, его надо чинить.
4. Пользователю, если он просил показать, — назови пути к файлам; чтобы открыть игру самому: `python3 -m http.server 8080` → http://localhost:8080 (или двойной клик по `index.html`).

Точечный снимок с произвольным размером: `tools/shot.sh out.png 820 1180 "<js>" 1.5`. Подробности и ограничения — `docs/kb/testing.md`.
